# Twitter Sentiment Analysis using RNN

## Overview

This project builds a **Recurrent Neural Network (RNN)** to classify tweets into three sentiment categories:

* Positive
* Neutral
* Negative

---

## Features

* Text preprocessing and cleaning
* Tokenization
* Padding sequences
* RNN model using **SimpleRNN**

---

## Libraries Used

* Python
* TensorFlow / Keras
* Pandas
* NumPy

---

## Dataset

Twitter dataset containing approximately **20,000 tweets** labeled with sentiment classes.

---

## Model Architecture

* Embedding Layer
* SimpleRNN Layer
* Dense Layer
* Softmax Output Layer

---

## Results

The model achieved **strong validation accuracy** in classifying tweet sentiments.

---

## Future Improvements

* Use **GRU or LSTM** for improved sequence learning
* Hyperparameter tuning
* Train on a **larger dataset**
