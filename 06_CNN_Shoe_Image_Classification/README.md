# Shoe Image Classification using CNN

## Overview

This project builds a **Convolutional Neural Network (CNN)** to classify shoe images into three categories:

* Boots
* Sandals
* Slippers

The model learns visual patterns from images and predicts the correct shoe category.

---

## Features

* Image preprocessing and normalization
* CNN architecture using **TensorFlow/Keras**
* Model training and evaluation
* Prediction on test dataset

---

## Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib

---

## Dataset Structure

```
train/
   Boots
   Sandals
   Slippers

test/
   images
```

---

## Model Architecture

The CNN model includes:

* Conv2D layers
* MaxPooling layers
* Flatten layer
* Dense layers
* Dropout for regularization

---

## Results

The model achieved **high accuracy** on the shoe image classification task.
